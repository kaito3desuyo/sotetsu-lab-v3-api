# ロードマップ（api）

2026-10-23 に棚卸しした、次のマイルストーンのうち api が関わる分。各マイルストーンの spec・計画・ADR は着手時に `docs/superpowers/` と `docs/adr/` に書く。

## 全体の順番

M0 後始末 → M1 登録制 ② → M2 SSR → M3 臨時列車 → M4 API の外部公開。M5 過去の目撃データの補完（段1：解析）は M1 と並行。M6 平日・土休日の取り違えの修正は、いつでも差し込める。M7 祝日データの延長は 2027 年のうちに、client の M8 index.html のキャッシュは M1 の告知日より前に。M9〜M11 はいつでも差し込める。M12〜M15 の機能は M1 の公開の後（M13 は公開直後が効く）、M16 ライブラリはいつでも、M17 は M5 段2 と一緒に。M18 投稿の見回りは M1 の公開と同じ頃に、M19 障害の見張りはいつでも（早いほどよい）、M20〜M22 はいつでも差し込める。M26 免責事項・プライバシーポリシーは M1 の告知日より前に、M23 開発用 DB の分離は M3・M17・M20 より前に、M24・M25 はいつでも。M27 登録者限定の MCP サーバーは M4 の後に。M28 地図の列車位置情報は M2・M3 の後に、M12・M14 の近くで。性能と費用削減も並行で進めるが、手をつける前に計測する。他のリポジトリの分は、それぞれの `docs/roadmap.md` にある。

## M5 の元データの読み方

- 相鉄館の `past_ope_data/`: Shift_JIS の CSV。1 行が `編成番号,運番,区分,月/日,時分[,投稿者]`。年はフォルダ名から決める
- 1 ファイルは「その日の編成ごとの最新」を切り取ったもの。日をまたいで同じ行が重なり、途中の目撃は残っていない
- 区分の小文字 `a`/`p` は毎日 2 時の自動順送りで出た運番であり、目撃ではない
- 運番 `100` は「休」（どの運用にも入っていない）
- `770607004` は当時の表記で 7706(7004)、`97007` は旧7007。呼び方の規則（横浜側先頭車＋F）では 7004F
- 当時の運用図表（`un-yo-zuhyo*.txt`）が 2000/04〜2012/04 の改正ごとに残っている
